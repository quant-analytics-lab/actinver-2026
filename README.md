# Actinver-2026
# Systematic Investment Strategies Lab

## Overview

This project is a quantitative investment research experiment designed to compare different approaches to portfolio construction and investment decision-making.

Using the Reto Actinver 2026 investment simulator as an experimental environment, four independent investment strategies are developed, implemented, and evaluated under comparable market conditions.

The objective is not simply to maximize portfolio returns.

Instead, the project explores a broader question:

> Can systematic, data-driven investment processes produce more consistent and explainable decisions than discretionary investing?

Each strategy follows a different investment philosophy and uses its own decision rules, data sources, portfolio construction methodology,
and risk controls.

All strategies begin with the same simulated capital.
**Initial Capital: MXN $1,000,000**

The strategies are evaluated independently and compared using common performance and risk metrics.
